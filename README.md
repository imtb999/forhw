# Flutter Homework

| Assignment | Project | Description |
| --- | --- | --- |
| LAB 5 / Milestone 1 | [lab5_sneaker_store](lab5_sneaker_store) | Responsive sneaker catalog and product detail screen |
| LAB 6 | [lab6_registration](lab6_registration) | Registration, live form validation, role selection and navigation to the catalog |
| LAB 7 | [lab7_navigation](lab7_navigation) | BottomNavigationBar tabs, detail screen with arguments, Navigator.push / pop |
| LAB 8 | [lab8_catalog_feed](lab8_catalog_feed) | ListView.separated / GridView.builder, Pull-to-Refresh, Swipe-to-Delete with UNDO, empty state |
| LAB 9 | [lab9_global_cart](lab9_global_cart) | Global cart with Provider + ChangeNotifier, live AppBar badge, Cart screen with remove/UNDO, total and Clear All |
| LAB 10 | [lab10_cloud_product_explorer](lab10_cloud_product_explorer) | Live HTTP sneaker catalog (JSON from this repo), retry and refresh, Hero detail carousel and share deep link sheet |
| LAB 11 | [lab11_offline_vault](lab11_offline_vault) | SharedPreferences theme pre-load, username persistence, JSON-serialized notes with add/toggle/delete and cold restart survival |
| LAB 12 | [lab12_bloc_shop](lab12_bloc_shop) | AuthCubit with Equatable states, BlocConsumer login (SnackBar/navigation vs spinner), event-driven CartBloc with live badge and Cart screen |
| LAB 13 | [lab13_photo_diary](lab13_photo_diary) | Geotagged photo diary: camera/gallery with image_picker (compressed), GPS with geolocator, runtime permissions and offline diary feed |

Each folder is a separate Flutter project with its own README. Open the assignment folder in VS Code, run `flutter pub get`, select a device and press F5.

LAB 5 starts with the catalog. LAB 6 starts with registration and includes the catalog as the next screen. The two projects have different application IDs so they can be installed side by side.
